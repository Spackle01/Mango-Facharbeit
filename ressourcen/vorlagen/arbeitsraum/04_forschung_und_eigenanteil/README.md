# 04 – Forschung & Eigenanteil

Der Eigenanteil ist das Herzstück deiner Facharbeit (theoretisch oder empirisch).

## Mögliche Methoden für den Eigenanteil:
1. **Empirische Befragung / Online-Umfrage**:
   - Fragebogen erstellen (z. B. mit 5-stufigen Skalen, offenen/geschlossenen Fragen).
   - Stichprobe festlegen, durchführen, Daten auswerten & visualisieren (Diagramme).
2. **Qualitatives Experteninterview**:
   - Interviewleitfaden erstellen, Fachkraft interviewen, Gespräch transkribieren & Kernaussagen analysieren.
3. **Beobachtung / Fallstudie**:
   - Systematische Beobachtung (z. B. in einer Einrichtung/Praxis) anhand von Beobachtungsbögen.
4. **Experiment / Praxistest / Modell**:
   - Durchführung eines Versuchs, Dokumentation mit Messwerten und Fotos.
5. **Vergleichende Dokumenten- / Medienanalyse**:
   - Strukturierte Kriterienanalyse von Fachtexten, Gesetzestexten oder Kampagnen.
