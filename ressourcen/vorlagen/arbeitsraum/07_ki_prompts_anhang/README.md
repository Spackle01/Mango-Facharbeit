# 07 – KI-Nutzung und Gesprächsverläufe für den Anhang

## Vorgabe der Schule (Handreichung 3.6, verbindlich)

- KI-Einsatz im Text kennzeichnen:
  `Erstellt mithilfe von [KI-Tool]. Prompt 1: [Prompt nennen]; Prompt 2: [Prompt nennen]`
- **Die gesamten Gesprächsverläufe** im Anhang anfügen.
- KI-Tools im Literaturverzeichnis als Hilfsmittel aufführen: `Hilfsmittel (Name des KI-Tools): URL, Datum des letzten Zugriffs.`
- KI-Ergebnisse sind keine wissenschaftlichen Belege.

## So hilft die App

Die App speichert jeden Chat. Über „Arbeitsraum → Gesprächsverläufe exportieren“ entsteht hier eine Datei mit allen Gesprächen (Datum, Anbieter, vollständige Prompts und Antworten). Diese Datei ist die Grundlage für die Anlage „Vollständiger Verlauf der KI-Gespräche“.

In `ki_protokoll.md` kannst du zusätzlich festhalten, welche Prompts du in welchem Kapitel verwendet hast.
